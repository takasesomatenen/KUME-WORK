# SANSYA.LSP 三斜面積根拠計算作図

閉じたポリライン（や、線分・円弧で囲まれた領域）を三角形に分割し、底辺・高さ・
面積を自動作図して求積表を作成する AutoLISP ツールです。
（原作 (C) T.Sugimoto 2005〜2018）

## コマンド

`SANSYA` を実行すると設定ダイアログが開き、3つのモードを選べます。

| モード | 内容 |
| --- | --- |
| 三斜（自動） | 図形から自動で三角形分割し、寸法・面積記号・表を作図 |
| 個別 | 3点を手動で指示して三角形を1つずつ作図 |
| 集計 | 図面上の面積記号(AMARK)を選び、面積を合計して表を作成 |

## 基本の使い方（三斜・自動）

1. `SANSYA` を実行し、ダイアログで **「記号開始番号」に `A1` など**を入力して
   三斜（自動）を選ぶ。
2. **三斜計算したい閉じたポリラインを1本クリックで選択**する。
3. 選んだ図形が**一括で三角形に分割**され、寸法・面積記号・求積表がまとめて作図
   される。

### 記号（番号）の付き方

「記号開始番号」に入れた値から連番で振られます。

| 開始番号 | 付き方 |
| --- | --- |
| `A1` | A1, A2, A3, A4 … |
| `B1` | B1, B2, B3, B4 … |
| `1`  | 1, 2, 3, 4 … |
| `A`  | A, B, C, D … |

## Ver.1.16 での変更点（2026.07.07）

### 1. 高速化（抜本対応）

単純な図形でも遅かった原因（図形の複雑さに依らない固定コスト）を解消しました。
操作感・見た目・出力・計算/丸めロジックは変えていません。

- **ini をメモリにキャッシュ**：従来は三角形を1枚描くたびに `sansya.ini` を
  ディスクから読み直していた（`SANSTN` がネットワーク上だと特に致命的）。1回だけ
  読んで使い回すようにした。
- **レイヤ一覧の再取得を削減**：ダイアログを開くたびに全レイヤ列挙＋ソートを
  12回行っていたのを1回に。→ ポップアップの立ち上がりが軽くなる。
- **描画を `entmake`（直接生成）へ**：`command "line/text/pline"` のコマンド
  オーバーヘッドを排除。レイヤも各図形で直接指定し `CLAYER` 切替の連打を廃止。

### 2. 「点指示」による境界自動検出（オプション：非閉領域・お弁当分割）

三斜（自動）で図形を選ばずに `P`（点指示）を選ぶと、クリックした点を囲む境界を
AutoCAD の `BOUNDARY` で自動検出して三斜計算します。**閉じたポリラインの中に
線分（割線）が入って複数エリアに区切られている場合**でも、各エリアの内側を順に
クリックすれば処理できます（線分・円弧・ポリラインなど囲みの種類は不問）。

> **注意**: 区切りの線分は外周まで届いて領域を閉じている必要があります。隙間が
> あると分割されません。端点をスナップで接続するか `HPGAPTOL` を調整してください。

### 3. 不具合対策・堅牢化

- **ini 読み込みの堅牢化**: 旧バージョン・破損・空欄のある `sansya.ini` でも、
  不足フィールドを既定値で補完し、`nth` 参照によるエラーを防止。
- **選択チェック強化**: 三斜（自動）で閉じていない図形を選んだ場合は、無言で
  終わらず点指示に切り替えて案内。
- **集計チェック**: 選択内に有効な面積記号(AMARK)が無い場合は、空の表を作らず
  メッセージを表示。
- **個別作図の操作性**: 各点の指示プロンプトを明確化し、作図数・終了時の合計を表示。

## インストール / 動作環境

`ACADPREFIX` ドライブ直下の `klib/klib.cfg` にインストールパスが記述されている
必要があります（原作の構成に準拠）。ダイアログ定義ファイル `sansya.dcl` を
`SANDIR` に配置してください。

ファイルの文字コードは Shift-JIS(CP932)、改行は CRLF です（AutoCAD 互換のため）。
